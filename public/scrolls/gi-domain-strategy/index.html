3 · Current State & Reconciliation

Live today: the show's interim home is dojo.ninja360.co/gi/site/ — the full six-page build plus the contestant signup page, on Cloudflare Pages, deployed from this Git repo. Every page in that build uses relative links on purpose, so the whole tree lifts to the domain root verbatim once it's wired — no code changes beyond flipping robots and uncommenting each page's canonical tag (the LAUNCH CHECKLIST comment already in every head).
Domain registration — unresolved (content export Q6). Checked from here on 2026-08-30: none of generationallyincorrect.com, www.generationallyincorrect.com, .net, .fm, .co, or genincorrect.com resolve — no A record on any of them. This sandbox has no whois, so that's consistent with "not registered yet," not full proof. Whoever holds registrar access should confirm directly and register the set above before it's a real gap.
Two separate SPF/DKIM/DMARC jobs, not one. The GHL build spec already flags ninja360.net's email auth as unset (GHL system mail lands in spam until that's fixed). This scroll's domain-email item is a different domain — generationallyincorrect.com's own SPF/DKIM/DMARC, needed before contestant mail sends from that domain. Neither fixes the other.
/apply and /audition already work today. Both now 301 to the built signup page inside the interim mount — dojo.ninja360.co/gi/site/apply and /gi/site/audition → /gi/site/be-on-the-show/, ?src= tracking preserved. be-on-the-show/ stays the canonical page underneath either slug — nothing already printed or QR-coded against it breaks.
/listen — not built yet, on purpose. Spotify and Apple Podcasts URLs don't exist until the show actually publishes somewhere on those platforms. Building the hub now would mean fabricating links or shipping dead ones. Ready to build the moment real platform URLs land — YouTube (@Gen.Incorrect) is the only one that's real today.
